# Photography POV Cloud Darkroom — Design Specification

日期：2026-08-27

狀態：世界觀與第一個手機構圖已由 Oscar 確認，可進入互動原型

## 目標

將首頁的 Photography 區塊重新設計成第一人稱攝影世界

首頁 Hero 與 About 完全保留

第一階段只製作隔離的可操作原型，不直接替換正式 Photography 區塊

原型確認後，才整合進首頁並重新部署

## 核心概念

一句話：真實房間漂浮在雲層上，暗房逐漸侵蝕空間，使用者透過 Oscar 手中的相機進入攝影作品

### 已鎖定的世界

- 第一人稱 POV，不出現正臉
- 粗糙水泥、霧黑金屬、潮濕玻璃
- 真實房間逐漸長出暗房紅燈、相紙與顯影盤
- 窗外是粉白雲海
- 雲色以霧粉為主、珍珠白提亮，少量淡奶油黃藏在高光
- 禁止橘色夕陽、琥珀濾鏡與全畫面暖色偏色
- 室內維持中性冷灰，紅光只在暗房局部出現

### 已鎖定的人物線索

- 深紫黑寬鬆抓絨外套
- 落肩、寬袖、袖口自然堆在手腕
- 左手無名指只有一枚素面銀戒
- 不出現手錶或其他飾品

### 已鎖定的相機

- 無品牌黑色復古旁軸數位相機
- 使用者拍攝時，鏡頭朝窗外，觀眾看到相機背面與螢幕
- 右手拇指位於機械轉盤附近
- 往下滑時，拇指與轉盤同步轉動
- 禁止 Logo、假文字、反向鏡頭與不可能的握法

## 故事與互動順序

原型使用一段連續的手機縱向捲動，共六個 beat

1. 房間仍然接近黑暗，潮濕窗簾佔據前景
2. 左手拉開窗簾，粉白雲海照進水泥房間
3. 右手抬起相機，暗房紅燈與相紙逐漸出現
4. 快門閃光遮住剪接點，相機背面螢幕亮起
5. 使用者繼續往下滑，拇指同步轉動轉盤，依序切換五組作品
6. 選中的作品從相機螢幕擴大為真正的 HTML 作品卡，使用者可以進入作品

## 五組作品

原型直接使用網站既有攝影素材，不再生成假作品

1. JOYCE 純愛俱樂部
2. 平面攝影精選
3. 戶外人像
4. PARK2 國際親吻日
5. 婚禮紀實

每一組只顯示一張代表圖、極短標題與年份／類型

所有可讀文字使用真正的 HTML 疊在畫面上

生成圖片內禁止放文字與介面

## 響應式策略

### 手機優先

- 不將網頁鎖成 9:16
- 第一個畫面使用實際裝置可見高度
- 主要構圖以約 390 × 844 CSS pixels 檢查
- 內容沿頁面繼續往下捲動
- 互動控制使用直向捲動，不要求橫向拖曳
- 所有可點擊區域至少 44 × 44 CSS pixels
- 底部保留至少 72px，避開既有 MobileNav

### 桌機

- 重新構圖為橫向，不放大手機裁切
- 雲窗留在左中區，相機與手放在右下區
- 滑鼠滾輪沿用同一組 beat
- 鍵盤方向鍵可切換作品

## 視覺層與內容層

### 視覺層

目前確認的生成圖只作 composition placeholder

Oscar 已指出目前圖片有髒感

原因包含生成圖本身的顆粒與紋理，以及網站既有的全站 grain 疊層

最終素材將改用 SeaArt Pro 重新生成，目標為乾淨空氣感、平滑漸層與較少皮膚／水泥雜訊

### 內容層

- 作品名稱、年份、類型與連結全部由 HTML 呈現
- 相機螢幕只作視覺框，不承擔 AI 生成文字
- 在圖片替換前，互動和排版應可獨立完成及驗證

## 動態規則

- 捲動驅動，不使用自動播放敘事
- 快門白光只作一次剪接遮罩，不連續閃爍
- 每次作品切換提供輕微轉盤刻度感
- 動畫只使用 transform 與 opacity 為主
- `prefers-reduced-motion` 下停用視差與轉盤旋轉，保留直接切換
- 使用者快速滑動時仍一次只前進一格，避免跳過作品

## 原型邊界

第一階段建立隔離路由 `/concepts/photography-pov`

原型不修改首頁 Hero、About 或正式 Photography 元件

原型通過手機與桌機檢查後，才將選定版本整合進首頁 Photography page index 2

## 驗收標準

- 手機可順暢往下滑，不被內外兩層 scroll 卡住
- 拉窗簾、抬相機、快門與作品切換有清楚先後
- 相機鏡頭方向符合真實拍攝物理
- 五組作品皆使用真實既有素材
- 標題在手機上可讀且不遮住手與相機
- 沒有生成文字、Logo 或錯誤 UI
- reduced-motion 模式仍可完整瀏覽五組作品
- 首頁 Hero 與 About 沒有任何改動
- build 通過，原型路由在手機與桌機皆可載入

## 暫不處理

- SeaArt Pro 最終資產生成
- 正式首頁 Photography 替換
- Video、AIGC、Projects 與 Contact 的大幅改版
- 全站 grain 移除
- 音效與真實觸覺回饋
